# KOALA Study Winter 2026
## Prerequisites
- Python 3.14
- Jupyter Notebook
- Matplotlib
- Seaborn
- Sqlalchemy
- PostgreSQL

Note: Jupyter Notebook is used for building data analysis while Python files are completed files

## Tasks
Task numbers are assigned based on the order of the tasks completed by Group 1
- Task 1 - Statement Coverage (No AI) - Grade Scale
- Task 2 - Branch & Loop Coverage (No AI) - Summarize Numbers
- Task 3 - Statement Coverage (AI) - Classify Triangle
- Task 4 - Branch & Loop Coverage (AI) - Process Cart

All task directory include Jupyter Notebooks for development of graphs and complete Python files to generate them. Notebooks were primarily used for development and testing.
SQL files are also included for query development and to check the output.

Combined directory includes full, unfiltered queries of all four tasks and was mainly used for testing purposes.
