For pytest
Statement and Branch Coverage:
pytest --cov=starter_code --cov-report=term-missing <test_file>
Batch:
pytest --cov=starter_code --cov-report=term-missing test_*.py

Path Coverage:
pytest --cov=starter_code --cov-branch --cov-report=term-missing:skip-covered <test_file> -v
Batch
pytest --cov=starter_code --cov-branch --cov-report=term-missing:skip-covered test_*.py -v

For unittest
Statement Coverage:
coverage run --source=starter_code <test_file>
coverage report -m
Batch:
coverage run --source=starter_code -m unittest discover -s . -p "test_*.py"
coverage report -m

Branch Coverage:
coverage run --source=starter_code --branch <test_file>
coverage report -m
Batch:
coverage run --source=starter_code --branch -m unittest discover -s . -p "test_*.py"
coverage report -m

Path Coverage:
coverage run --source=starter_code --branch <test_file> -v
coverage report -m --skip-covered
Batch:
coverage run --source=starter_code --branch -m unittest discover -s . -p "test_*.py" -v
coverage report -m --skip-covered

NOTE: PATH COVERAGE IS APPROXIMATED
